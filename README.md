# Warnes Herramientas — Landing

Landing page moderna, minimalista y con toque industrial para **Warnes Herramientas**.
Sitio estático (HTML + CSS + JavaScript), sin dependencias ni build.

## 🎨 Diseño
- **Estilo:** moderno · minimalista · industrial
- **Paleta:** rojo `#E22B22` + grafito/negro `#121316`
- **Tipografías:** Space Grotesk (títulos) · Inter (texto)

## 📁 Estructura
```
index.html          → página principal
assets/styles.css   → estilos
assets/script.js    → menú mobile + año del footer
```

## ▶️ Ver el sitio localmente
Abrí `index.html` en el navegador, o levantá un servidor simple:
```bash
python3 -m http.server 8000
# luego abrir http://localhost:8000
```

## ✏️ Datos pendientes de completar
Buscá los comentarios `TODO` en `index.html` para cargar los datos reales:
- Dirección
- Teléfono
- Email
- Número de WhatsApp (formato `549...` en el enlace `https://wa.me/`)
- Horarios (verificar)

## 🚀 Publicación (GitHub Pages)
1. Settings → Pages → Source: rama del repo / carpeta `/root`.
2. El sitio queda online en la URL que indica GitHub Pages.
