## Recomendaciones
- Formato PNG (idealmente con fondo transparente) o SVG.
- Alto parecido entre todos para que se vean parejos (la web los ajusta a 60px de alto).
- Si el archivo de una marca no está, el carrusel muestra el nombre en texto como respaldo.

## Cómo subirlos (desde GitHub, en el navegador)
1. Entrá a esta carpeta en la rama de trabajo.
2. "Add file" → "Upload files".
3. Arrastrá los logos (renombrados como arriba) y confirmá el commit.
La web se actualiza sola en ~1 minuto.
